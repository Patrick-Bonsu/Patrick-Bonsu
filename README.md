# Patrick Yeboah Bonsu

Biomedical Engineering graduate (University of Toronto) building machine learning systems for
clinical data — ECG classification, ICU risk prediction, medical imaging, and reinforcement
learning safety analysis.

Recent work focuses on interpretability and safety: checking what a trained model actually
represents (linear probing, Grad-CAM, activation patching), and stress-testing a reinforcement
learning agent for reward hacking and distributional shift.

More detail on each project: [patrick-bonsu.github.io/portfolio](https://patrick-bonsu.github.io/portfolio/)

---

### Projects

| Project | Summary | Result |
|---|---|---|
| [ECG Arrhythmia Classification](https://github.com/Patrick-Bonsu/ecg-arrhythmia-classification) | 1D ResNet + mechanistic interpretability on 21.8k PTB-XL ECGs | Macro-AUC 0.913 |
| [Clinical RL Safety Analysis](https://github.com/Patrick-bonsu/rl-clinical-agent) | PPO insulin-dosing agent; reward hacking & distributional-shift analysis on SimGlucose | 5 environment bugs found & fixed |
| [ICU Mortality Prediction](https://github.com/Patrick-Bonsu/icu-mortality-prediction) | Temporal Transformer + XGBoost on MIMIC-IV vitals | AUROC 0.838 · [demo](https://huggingface.co/spaces/Patrick-Bonsu/icu-mortality-demo) |
| [RAG over PubMed Sepsis Literature](https://github.com/Patrick-Bonsu/rag-pubmed-sepsis) | PubMedBERT + ChromaDB + local Llama 3.1, PMID-grounded answers | Faithfulness 0.84 |
| [Pediatric Brain Tumor Segmentation](https://github.com/Patrick-Bonsu/medical-seg-brats-ped) | 3D U-Net on BraTS-PED MRI volumes | Dice 0.869 (whole tumor) · [demo](https://huggingface.co/spaces/Patrick-Bonsu/brats-ped-demo) |
| [Seizure Prediction (CHB-MIT)](https://github.com/Patrick-Bonsu/seizure-prediction-chbmit) | Seizure vs. non-seizure classification on scalp EEG | In progress |
